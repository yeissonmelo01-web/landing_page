## 📋 Descripción General
SecureCam es una landing page de alta conversión diseñada para empresas y hogares que buscan soluciones profesionales de videovigilancia.  
El sitio permite a los usuarios:  
- Explorar kits de cámaras (análogas e IP).  
- Revisar características técnicas de cada plan.  
- Interactuar con un componente de preguntas frecuentes (FAQ).  
- Utilizar un formulario inteligente con persistencia de datos para solicitar cotizaciones personalizadas.  

El desarrollo se realizó bajo una metodología estructurada en 5 fases, con apoyo de Inteligencia Artificial (Google AI Studio – Gemini) para optimización de copy, lógica y auditoría.

---

## 🛠️ Tecnologías Utilizadas
- HTML5 Semántico: estructura clara y optimizada para SEO y accesibilidad.  
- CSS3 con Design Tokens: uso de custom properties en `:root` para escalabilidad y consistencia visual.  
- JavaScript ES6+ Modular: lógica encapsulada con patrón IIFE para mayor mantenibilidad.  
- IA Asistida: Google AI Studio (Gemini) para generación de contenido, validación y auditoría del código.  

---

## 📌 Características Clave
- 📝 Formulario con Autoguardado: captura de datos en tiempo real mediante el evento `input`, con almacenamiento en `localStorage` bajo un namespace propio.  
- ✅ Control de Estado de Usuario: detección de clientes que ya enviaron su solicitud, ocultando el formulario y mostrando un mensaje de agradecimiento personalizado.  
- 📦 Biblioteca de Componentes Modulares: snippets reutilizables (Hero, FAQ interactivo, Tarjetas de Planes, Footer legal) diseñados con enfoque Mobile-First.  
- 🔗 Integración con API Real: envío de datos mediante POST a servicios externos (Formspree / EmailJS) para recepción efectiva de leads.  

---

## 📈 Metodología de Desarrollo
El proyecto se construyó siguiendo un flujo de trabajo en 5 fases:  
1. Diseño inicial y publicación en GitHub Pages.  
2. Auditoría crítica del código generado por IA.  
3. Implementación de persistencia de datos en el formulario.  
4. Creación de biblioteca de componentes modulares.  
5. Integración final y entrega con memoria reflexiva.
